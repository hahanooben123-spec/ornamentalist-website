ORNAMENTALIST / PRIVATLIV

Dit arbejde.
På din enhed.

Senest opdateret: 18. oktober 2026.

Denne politik beskriver den nuværende Ornamentalist-app til iPad og denne hjemmeside. Ansvarlig for appen og henvendelser er Chris Mortensen. Kontakt: Chrismortensen1997@outlook.dk.

Data i appen

Ornamentalist kræver ingen brugerkonto. Appen indeholder ikke reklamer, sporing eller tredjepartsanalyse og sender ikke selv dine tegninger eller brugsdata til udvikleren. Tegninger, lag, importerede billeder og indstillinger behandles lokalt på din enhed.

Opbevaring og sletning

Projekter gemmes i appens lokale dokumentmappe. Penselvalg og andre indstillinger kan gemmes som lokale præferencer. Du kan slette projekter i galleriet. Sletter du appen og dens data, fjernes dens lokale indhold normalt også. Eksporterede filer, systemets sikkerhedskopier og eventuelle kopier i andre tjenester skal håndteres separat. Apples sikkerhedskopiering kan omfatte appdata afhængigt af dine enhedsindstillinger.

Import og eksport

Appen giver mulighed for at vælge billeder og filer via iPadOS. Det valgte indhold bruges i tegningen. Når du eksporterer eller deler et projekt eller et billede, vælger du selv modtager eller destination. Behandlingen hos den valgte tjeneste følger dens egne vilkår og privatlivspolitik.

TestFlight og Apple

Hvis du bruger appen gennem TestFlight, kan Apple behandle testoplysninger, nedbrudsrapporter og feedback efter sine egne betingelser og dele oplysninger med udvikleren. Det er adskilt fra appens lokale lagring. Se Apples privatlivspolitik.

Når du kontakter support

Sender du en mail, behandler vi din mailadresse, besked og eventuelle vedhæftninger for at besvare henvendelsen og undersøge fejl. Grundlaget er vores legitime interesse i at yde support og vedligeholde appen. Send kun oplysninger, der er relevante for problemet. Mail håndteres via Microsoft Outlook. Supportoplysninger opbevares, så længe det er nødvendigt for henvendelsen og relevant opfølgning, og slettes derefter.

Denne hjemmeside

Siden bruger ingen egne cookies, analyseværktøjer eller kontaktformularer og indlæser ingen eksterne skrifttyper. Hjemmesiden hostes på GitHub Pages. GitHub kan behandle tekniske oplysninger som IP-adresse i forbindelse med drift og sikkerhed. Se GitHubs privatlivspolitik.

Dine rettigheder

Hvis vi har personoplysninger om dig, eksempelvis fra support, kan du kontakte os om indsigt, rettelse, sletning, begrænsning og indsigelse samt dataportabilitet, hvor det gælder. Vi har ikke adgang til dine lokalt gemte tegninger. Du kan klage til Datatilsynet.

Ændringer

Politikken opdateres, hvis appens datahåndtering ændres. Den gældende dato står øverst på siden.
